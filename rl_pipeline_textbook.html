02动作重定向 (GMR IK)

动作重定向（Motion Retargeting）将人体 3D 姿态映射到小派机器人的 22 自由度关节空间。本项目使用基于 IK（逆运动学）的重定向方法，通过 mink 库在 MuJoCo 中进行任务空间求解。

pipeline/02_retarget.py → GMR/scripts/gvhmr_to_robot.py

GMR 核心原理

class GeneralMotionRetargeting:
    """GMR: 通用动作重定向器"""
    def __init__(self, src_human, tgt_robot, actual_human_height=None,
                 solver="daqp", damping=5e-1, use_velocity_limit=True):
        # 加载机器人 MuJoCo 模型
        self.xml_file = str(ROBOT_XML_DICT[tgt_robot])
        self.model = mj.MjModel.from_xml_path(self.xml_file)

        # 加载 IK 配置 (JSON)
        with open(IK_CONFIG_DICT[src_human][tgt_robot]) as f:
            ik_config = json.load(f)

        # 根据实际人体高度计算缩放比例
        ratio = actual_human_height / ik_config["human_height_assumption"]
        for key in ik_config["human_scale_table"]:
            ik_config["human_scale_table"][key] *= ratio

        # 构建 IK 任务
        self.tasks1 = []  # 第一组 IK 任务
        self.tasks2 = []  # 第二组 IK 任务
        self.setup_retarget_configuration()

IK 求解流程（每帧）

  1. 缩放：根据人体实际高度比例缩放骨骼数据（scale_human_data）
  2. 偏移：应用位置和旋转偏移量使人体姿态对齐机器人基座（offset_human_data）
  3. 双阶段 IK：先求解下半身任务，再求解上半身任务，每阶段最多迭代 10 次
  4. 约束：关节位置限位 + 关节速度限位（3π rad/s）
def retarget(self, human_data):
    self.update_targets(human_data)

    # 第一阶段 IK（如下半身）
    vel = mink.solve_ik(
        self.configuration, self.tasks1, dt,
        solver="daqp", damping=5e-1,
        limits=[mink.ConfigurationLimit(self.model),
                mink.VelocityLimit(self.model, VELOCITY_LIMITS)]
    )
    self.configuration.integrate_inplace(vel, dt)

    # 迭代直到收敛 (误差变化 < 0.001)
    while curr_error - next_error > 0.001 and num_iter < self.max_iter:
        vel = mink.solve_ik(...)
        self.configuration.integrate_inplace(vel, dt)
        num_iter += 1

    return self.configuration.data.qpos.copy()  # 返回关节角度

关键参数

IK 求解器使用 solver="daqp"，阻尼系数 damping=5e-1。关节速度限位设为 3π rad/s。如果重定向结果出现抖动，可以增大 damping 或减小 max_iter。如果跟踪不准，检查 IK config 中的 human_scale_table 是否匹配演示者的实际身高。

关键代码深度解读

GMR 的人体数据缩放

不同演示者身高不同，IK 配置中有一个假设身高。代码在 本地坐标系中进行缩放，保持肢体比例不变：

def scale_human_data(self, human_data, human_root_name, human_scale_table):
    root_pos, root_quat = human_data[human_root_name]

    # 根节点在世界坐标系中缩放
    scaled_root_pos = human_scale_table[human_root_name] * root_pos

    # 其他部位先在本地坐标系缩放，再转回世界坐标系
    for body_name in human_data:
        if body_name == human_root_name: continue
        local_offset = (human_data[body_name][0] - root_pos)
        human_data_local[body_name] = local_offset * human_scale_table[body_name]

    # 转回世界坐标
    for body_name in human_data_local:
        human_data_global[body_name] = (
            human_data_local[body_name] + scaled_root_pos,
            human_data[body_name][1]
        )

Sim2Sim 中的 PD 控制 + 策略推理

在 MuJoCo 验证中，策略输出的是关节位置的增量，通过 PD 控制器发送到关节：

def pd_control(target_q, q, kp, target_dq, dq, kd):
    """标准 PD 控制器"""
    return (target_q - q) * kp + (target_dq - dq) * kd

# 主循环（每 10 步推理一次）
if counter % control_decimation == 0:
    # 1. 构造观测向量（119 维）
    motioninput = np.concatenate([joint_pos, joint_vel])      # 44 维
    motion_ref_ori_b = rot_matrix[:2].reshape(6)               # 6 维
    omega = angular_velocity                                    # 3 维
    obs = [motioninput, motion_ref_ori_b, omega,
           qpos - default_pos, qvel, prev_action]              # 合计 119

    # 2. ONNX 推理
    action = policy.run(['actions'], {'obs': obs, 'time_step': t})[0]

    # 3. 去标准化：action * scale + default
    target_dof_pos = action * action_scale + default_joint_pos

    # 4. PD 控制发送到关节
    tau = pd_control(target_dof_pos, qpos[7:], kp, zeros, qvel[6:], kd)
    d.ctrl[:] = tau

多仓库协同

本项目跨越三个 Git 仓库，通过子进程调用和共享数据格式（CSV / NPZ / PT）连接：

仓库路径职责
tree_PI/ pipeline/ Pipeline 编排脚本（5 个步骤的胶水代码）
HT_GVHMR-and-GMR/ GVHMR/ 视频 → 3D 姿态提取 + GMR 运动重定向
Mini-Pi-Plus_BeyondMimic/ source/whole_body_tracking/ RL 训练环境 + Sim2Sim 验证 + 真机部署

常见问题与调试

症状原因解决方案
GVHMR 输出骨架抖动 视频光照变化 / 自遮挡 确保视频帧率 ≥ 60fps，正面视角，背景简洁
GMR 重定向后关节角度突变 IK 求解不收敛或人体身高比例不匹配 增大 damping（如 5e-1 → 1e0），或指定 actual_human_height
训练不收敛 / reward 不增长 奖励权重不当 / 域随机化不足 检查 motion_body_pos.weight（建议 1.5），增加 physics_material 随机化范围
Sim2Sim 跟踪误差过大 Isaac Sim 与 MuJoCo 的物理差异 / PD 增益不匹配 调整 MuJoCo 中的 stiffness_array 和 damping_array
ONNX 推理输出 NaN 观测归一化未正确应用 确认 obs_normalization=True，检查 ONNX 元数据中的 default_joint_pos

环境注意事项

GVHMR/GMR 使用 Python 3.10 + conda 环境 gmr，RL 训练使用 Isaac Sim 5.0.0 自带的 Python 3.11 环境。两个环境的 pxr/USD 库版本冲突，需在 train.py 中通过 sys.path 操作解决（见 scripts/rsl_rl/train.py 开头的 Fix 1–9）。
